# About Me

I'm a **Computer Engineer** focused on **Linux systems, defensive security, system administration and automation**.

My technical path started with **hardware, operating systems, troubleshooting and networking**. Over time, that foundation led me deeper into Linux administration and cybersecurity.

Today I build small, practical tools with **Python, Bash and native Linux utilities** to inspect systems, review configurations, automate repetitive tasks and make technical information easier to understand.

I prefer starting with a simple question:

> **What problem is actually worth solving?**

I don't aim to build complexity for its own sake.

I prefer tools that are:

- Small enough to understand completely.
- Practical enough to test on a real Linux environment.
- Focused enough to solve one clear problem.
- Structured enough to evolve when there is a reason to do so.

📘 The Last Manual

Linux • Python • System Administration • Operational Handover

A small Linux tool built around a simple operational problem:

> What happens when you inherit a server that someone else used to manage?



The project compares a documented reference with the current system state and highlights discrepancies that require human review.

It focuses on reducing uncertainty during system handover and administrative transition.

KNOWN
  ↓
Documented Reference
  ↓
Current System
  ↓
Comparison
  ↓
Discrepancies
  ↓
Human Review

The goal is not to decide what is "good" or "bad".

The goal is to establish a clear starting point.

Focus: Linux • Python • System Administration • Handover

🩺 El Médico Forense

Python • Linux • System Triage

A lightweight Python tool for performing an initial Linux system triage.

It checks selected system signals such as:

Disk usage

Memory

Listening TCP ports

SSH configuration


The tool produces both a readable console assessment and structured JSON output.

It is designed to identify conditions that require investigation, not to automatically declare a system compromised.

Focus: Python • Linux • System Triage

🎭 El Camuflaje

Python • OpSec • Information Handling

A small Python tool for preparing technical information before sharing it publicly.

It preserves useful structure while replacing configured sensitive or internal information such as:

IP addresses

Usernames

Hostnames

Internal paths

Other configured values


The principle is simple:

> Don't remove useful information. Hide only what you don't need to reveal.



Focus: Python • OpSec • Information Handling
